# OmyDs

**一个轻量、可定制的终端 AI 助手，记得重要的事，也能动手处理任务。**

简体中文 · [English](README.en.md)

OmyDs（O my DeepSeek）从日常终端使用出发：聊天、读写文件、执行命令，并在不同会话之间保留重要记忆。你可以调整它的表达方式，选择工作目录，明确决定它拥有多少行动权限。

长期方向是能够连接更多设备与服务的个人助手。目前提供终端应用；远程接入、家庭设备控制、定时任务和支付能力仍属于未来方向。

## 核心能力

- 自然语言调用文件读取、文件写入和 shell 工具。
- 新建、加载、保存多个会话，查看历史并返回会话菜单。
- 本地长期记忆，以及通过 agent.md 自定义角色和行为。
- 工作区自动、逐次确认、显式宿主机三种权限模式。
- 展示操作目的、预计影响、实际路径和命令。
- Markdown 输出、角色配色、斜杠命令建议与命令历史。

## 快速开始

### 环境要求

- Python 3.11+、[uv](https://docs.astral.sh/uv/)。
- 可用的模型 API 凭据；模型需支持工具调用。
- Linux：当前完整工具执行的支持目标。
- bubblewrap（bwrap）：用于隔离命令。
- setpriv（通常由 util-linux 提供）：用于宿主机模式。

系统工具请通过发行版包管理器安装。macOS 和 Windows 原生命令执行尚未支持；使用 WSL 时，在 Linux 环境内完成安装和运行。

### 配置并启动

下载或克隆仓库，在项目根目录执行：

~~~bash
uv sync
cp config.example.toml config.toml
cp agent.example.md agent.md
~~~

编辑 **config.toml**，填写 **[api]** 下的 **key、base_url、model**，然后启动：

~~~bash
uv run OmyDs
~~~

也可使用模块入口：

~~~bash
uv run python -m omyds
~~~

已有自己的配置时，不要再次复制示例覆盖。当前推荐从源码目录运行；上述步骤不会把启动命令安装到系统全局。

项目以 DeepSeek API 为主要使用目标，地址和模型名可配置。其他兼容接口的工具调用及扩展字段行为可能不同，需自行验证，不宣称兼容所有服务商。

## 使用

进入会话后直接描述任务，例如：

> 在当前工作区创建 notes.txt，写入今天的阅读计划。

> 读取 notes.txt，概括其中的事项。

默认工作区是项目下的 **sandbox/**。要处理其他项目，先指定已有目录：

~~~text
/set-project-root-in /absolute/path/to/project
~~~

支持 ~ 和相对路径；相对挂载路径以启动 OmyDs 时所在目录为基准。模型在下一次请求中会获知最新工作区与权限模式。

| 命令 | 用途 |
| --- | --- |
| /help | 查看命令帮助 |
| /history | 查看当前会话历史 |
| /return | 选择保存或放弃后返回菜单 |
| /retry | 继续未完成的模型请求 |
| /permissions | 查看当前权限与工作区 |
| /safe | 切换到工作区自动模式 |
| /permissions ask | 写入和命令执行前逐次确认 |
| /danger-full | 确认后开启当前会话的宿主机模式 |
| /set-project-root-in &lt;路径&gt; | 切换工作区 |
| /reset-project-root | 恢复默认工作区 |
| exit / quit | 退出程序 |

正常返回或退出时，有改动会询问是否保存；目前不是自动保存。请求失败时保留已有工具记录，/retry 不主动重放已执行的工具，但模型仍可能提出新的重复操作。

## 权限与执行范围

| 模式 | 工作区内文件 | shell 命令 | 工作区外文件 |
| --- | --- | --- | --- |
| workspace（默认） | 自动执行 | bwrap 隔离，免逐次确认 | 普通文件可单次询问，部分路径受限 |
| ask | 读取自动，写入询问 | bwrap 隔离，执行前询问 | 普通文件可单次询问，部分路径受限 |
| danger-full | 自动执行 | 宿主机当前普通用户权限 | 遵循系统权限，不逐次询问 |

工作区是真实目录，不是副本。整个目录包括隐藏文件都在操作范围内，误写或删除不会自动回滚。文件工具使用路径检查；隔离命令通过 bwrap 挂载工作区和只读系统运行库，并禁用命令的外部网络。隔离失败时不会自动改为宿主机执行。

danger-full 可以访问个人文件、联网，也可能读取凭据或改写 OmyDs。它不自动授予 sudo/root，拒绝从 root 进程启用，并通过 setpriv 限制执行程序时获得新增权限；这不构成文件系统或网络隔离。

模式仅对当前会话生效。进入其他会话时恢复默认模式和默认工作区。/safe 恢复隔离策略，但不撤销已执行的操作；切换目录本身不改变权限模式。

模型给出的“目的”和“预计影响”是说明，不是独立安全审计。提示词注入防御和沙箱都不能视为绝对保证。

## 角色、记忆与数据

| 内容 | 文件 | 何时加载 |
| --- | --- | --- |
| 角色与行为原则 | 项目根目录 agent.md | 进入会话 |
| 长期记忆 | ~/.omyds/memory.md | 进入会话 |
| 已保存会话 | ~/.omyds/sessions/*.json | 选择会话 |
| 斜杠命令历史 | ~/.omyds_history | 用于历史与输入建议 |
| API 配置 | 项目根目录 config.toml | 启动程序 |

角色配置优先级：**agent.md → agent.example.md → config.toml 中的 chat.system_prompt**。

长期记忆从同一次模型回复中的记忆标记提取，不另开请求筛选。可以手动编辑或删除条目，再重新进入会话。它不保证完美回忆，全文加载也会占用输入上下文。

已保存的会话保留消息记录，发送给模型的历史则按预算裁剪。目前没有自动检索旧会话的功能。提醒或日程写入记忆后，也不会自动变成后台任务。

**greet.toml** 设置启动问候文本；remind = false 关闭该文本，不控制 logo。

**本地保存不等于完全离线。** 对话、加载的记忆、系统提示和工具读取内容会随请求发送到配置的模型服务。会话文件可能包含工具结果和模型返回的推理字段。请勿公开个人配置、会话或记忆；.gitignore 不会自动取消对已跟踪文件的跟踪。
