# OmyDs (O my DeepSeek)

一个运行在终端里的 DeepSeek AI 助手。

## 功能特性 (v0.1.3)

- **多会话管理**：支持新建、加载多个历史对话，退出时自动保存记录。
- **AI 自动记忆**：基于大模型理解，自动提炼关键偏好并存入本地 `memory.md`，跨会话生效。
- **个性人设注入**：支持通过 `agent.md` 高度自定义 AI 性格与指令。
- **上下文防爆**：自动截断超长对话发送给 API，但本地 JSON 完整保留。
- **终端高级编辑**：支持上下方向键找回历史输入，支持左右键修改，完美兼容中文输入法。
- **安全沙箱（即将到来）**：限制文件读取范围，防止路径穿越攻击。

## 安装

```bash
git clone <你的仓库地址>
cd OmyDs
python -m venv .venv
source .venv/bin/activate
pip install -e .
```

## 配置

首次运行前，需要在项目根目录创建两个核心配置文件。这两个文件均已被 `.gitignore` 忽略，可放心填写私人信息。

### 1. API 配置 (`config.toml`)

新建 `config.toml`，填入你的 API Key：

```toml
[api]
key = "sk-在此填入你的真实API Key"
base_url = "https://api.deepseek.com"
model = "deepseek-chat"

[chat]
# 作为 agent.md 不存在时的备用提示词
system_prompt = "你是 OmyDs，一个简洁、直接的终端聊天助手。"
```

### 2. 人设与规则 (`agent.md`)

新建 `agent.md`，定义 OmyDs 的性格和系统指令（建议直接复制下面的模板）：

```markdown
你是 OmyDs（O my DeepSeek），一个运行在极客终端里的 AI 助手。

【性格设定】
- 说话风格直接、干脆，不说废话。
- 能用代码或列表回答的，绝不用长段落。
- 带有一点点黑色幽默和极客式的傲娇，但非常可靠。

【系统最高指令：记忆提取】
如果你在对话中发现了关于用户的个人事实、偏好、项目设定等需要长期记住的信息，你必须在回复末尾加上格式标记。

示例 1：
用户：请记住我叫张三，是个后端工程师。
助手：收到，张三。后端工程师，看来我们要经常和服务器打交道了。[MEMORY: 用户叫张三，职业是后端工程师]

示例 2：
用户：以后给我写代码记得用 4 个空格，别用 Tab。
助手：明白，4 个空格保平安。[MEMORY: 用户要求代码缩进必须使用 4 个空格而不是 Tab]

注意：如果没有需要记住的新信息，绝对不要输出 [MEMORY: ...] 标记。
```

## 使用说明

在终端输入 `OmyDs` 即可启动：

```bash
OmyDs
```

- 输入 `exit` 或 `quit` 退出。
- 聊天过程中直接说"记住我喜欢 xx"，AI 会自动提炼并保存到 `~/.omyds/memory.md`。
- 所有对话记录都保存在 `~/.omyds/sessions/` 目录下，按会话名字存为 JSON 文件，可直接用文本编辑器查看。

## 数据存储位置

OmyDs 的所有用户数据都存放在你的系统用户主目录下，不会污染项目 Git 仓库：

| 数据类型 | 存储路径 |
| --- | --- |
| 会话历史 | `~/.omyds/sessions/*.json` |
| 长期记忆 | `~/.omyds/memory.md` |
| 输入历史 | `~/.omyds_history` |
